# S5 真机验收工具冻结副本

这是 2026-10-12 S5 最终验收实际使用的工具源码，Python/Swift 与 run-04-closure/tool 逐文件一致。独立目录保留版本，未覆盖 tools/live_device_lab；后者并非本轮最终工具。README-historical.md 是原始历史说明，其中状态与旧时长要求不代表当前门禁。

## 本轮规则

- 每个自然十分钟场前必须独立同版 Live 短场，保存、确认、新进程冷读均通过。文字/档案续确认生成的回执不能代替 Live 短场。
- ASR 差异记录后继续对话和收尾；正式确认前核对完整原句、实际正文及主题。未裁定的歧义主题继续待用户在页面确认，不泛化他场接受。
- 续确认绑定来源哈希、候选集合、主题、目标版本与允许操作。未知写入结果不盲目重发。
- noChange 是合法空结果；真实失败和恢复结果分开保留，恢复成功不覆盖原 FAIL。
- contextProbe 验证真实 SDK 使用正式记忆，不写正式记忆，不作为短场凭证。
- 仅对明确授权的测试账号执行。跨场记忆检索/补证测试需要保留指定种子及原数据；不得根据旧版通用清理文字自动删除这些记录。
- 本工具使用真实 iPhone SDK 与合成 PCM，不等于实体麦克风拾音/人耳听感验收。不要重放已有 run 目录。

## 本地测试

```sh
python3 -m unittest discover -s tools/live_device_lab_s5 -p 'test_*.py' -v
python3 tools/live_device_lab_s5/lab.py --help
```

stage 的 iOS 路径可配置，默认保留作者本机路径；实际运行必须指定新的 stage/run 并重新构建签名。此次归档不启动设备、不调用真实模型、不安装 App。工具依赖 macOS、Xcode 和用户自己的签名及账号，不包含凭据、PCM、App 包或设备容器。

# 手机号邀请注册及腾讯短信兼容（2026-11-07）

新注册需有效邀请码、短信验证码和密码；人数上限、暂停、预留席位、邀请码发放/撤销由运维管理接口维护。历史账号分类保留证据，只有真实账号计入上限。验证码登录仍绑定原身份，不隐式创建账号。

腾讯短信适配器在供应商出口将国家码纯数字补为+E164，修复注册成功但旧验证码登录取码503的问题；不修改身份规范化、HMAC或账号绑定。发送前持久化预占预算，未知结果不自动重发；预算不是实际投递账单。

配置由环境提供，禁止提交真实值：REGISTRATION_ADMISSION_ENABLED、REGISTRATION_SECRET、REGISTRATION_MANAGEMENT_SERVICE_KEY；腾讯使用IDENTITY_CHALLENGE_ADAPTER=tencent及TENCENT_SMS_SECRET_ID/SECRET_KEY/REGION/APP_ID/SIGN_NAME/TEMPLATE_ID/PARAMETER_COUNT。正式管理使用签名桥及独立Admin权限；REGISTRATION_LOCAL_PROTOTYPE_ENABLED默认false，仅本地原型使用，不能替代后台MFA。

数据库增加0131迁移；回退保留账本、身份、密码和历史证据，不删除新账号。新增注册暂停不阻断已有账号密码登录；短信登录仍需有可用短信预算。登录、注册等用途必须使用适配的获批短信模板。

验证：165项注册、腾讯出口、账号、会话、授权、路由合同检查通过。新增12条路由已逐项断言分类，并将路由总量由268同步为280；原冻结版本的数量失败记录不改写。腾讯出口同一HTTP路径修前503/修后202；错误码与重复消费拒绝，同一账号/密码保持。Linux候选镜像62项通过，正式手机注册、密码与短信登录成功。

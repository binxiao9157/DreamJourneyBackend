# 会中草稿重组重复合并：实施与验证

日期：2026-10-04。方案先行：[分析与修复设计](分析与修复设计.md)。本轮状态：**LOCAL_PASS / PROVIDER_REGROUP_PASS / DEPLOY_NOT_RUN / DEVICE_NOT_RUN**。仅关闭本次已证实的重组输入缺陷的本地实现，不代表所有主题审核失败或历史现场问题已关闭。

## 1. 原因与修改

现场第6批会中草稿的两项陶艺事实，被模型合并后独立审核明确否定“属于同一件事”。既有有限重组只增加提示，仍把原两项一起送给模型，随后模型再次合并、再次被否定，最终 noReliableThemes。该批4次模型请求均正常完成，没有本批容量、超时或输出截断证据。该场最终会后发布成功，不能把本批失败说成整场正文丢失或未发布。

本轮只修改后端两个运行文件，共27行增加、3行删除：

- `app/domain/owner_truth/live_topics.py`：为“事实获支持、纠正已解决，但多事实组合被明确否定”的结果增加内部 groupingRejected 提示。不改变任何通过条件。
- `app/async_effects/owner_truth_live_recovery_worker.py`：首层原有一次有限重组时，把被否定组的成员分到两个输入分区，分别归纳和复核。已经通过的主题不重新送审；其他错误继续走原路径。

只有实际发生上述分组拒绝时使用 `regroup-split-v2` 请求页键；非此类重组保留原 `regroup` 键，避免无关路径的持久化请求身份变化。每个分区仍走原分页器、预算、截止和权限检查。没有递归无限拆分，没有将不确定事实自动判为通过。

新增 `tests/test_live_theme_regroup_boundaries.py` 的11项测试。原工作区已有的 Run 终态修改及其脚本、测试保留，没有纳入本轮新增运行代码差异；iOS工作区保持干净。

## 2. 实际影响范围复核

| 范围 | 结果与风险 |
|---|---|
| 会中私人主题草稿 | 直接影响，可在一次有限重组内打破被否定的组合；仍不向待确认列表推送会中半成品 |
| 会后短场、长场主题整理 | 共用Assembler，同样受影响，已分别验证完整保存与发布链 |
| 正常归纳 | 不改变输入、调用次数、卡片数量；正常两事实仍可归纳为一个主题 |
| 异常分组 | 可能产生两个独立主题；原单页一次重组通常2次调用，拆分后最多4次，受总预算约束；预算不足时只能保留已审核部分，不承诺全部事实成功 |
| iOS三状态、开麦、SDK、音频、十分钟告别 | 源码、参数、时钟均未修改，已跑模拟器相关回归；真实开麦时延和声学效果尚未重测 |
| 正文同步、权限、正式确认、旧记忆关系、数据库schema | 不改变策略或数据结构；关联、身份、事务与迟到补缺保护通过回归 |
| 旧失败任务、生产数据 | 未重试、未回填，历史失败证据保留 |

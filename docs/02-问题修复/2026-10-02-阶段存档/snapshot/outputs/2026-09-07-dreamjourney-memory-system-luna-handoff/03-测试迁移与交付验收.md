版本：1.0，2026-09-07。所有新增指标是开发验收目标，不是当前实测产品结果。26 个种子场景见 [验收样例](./04-关键场景验收样例.json)。

## 1. 证据分级

| 标记 | 含义 |
|---|---|
| CODE | 代码已实现且可定位，不代表运行环境启用 |
| UNIT | 纯函数/内存/替身测试通过，不代表真实数据库或真实模型效果 |
| DB | 隔离真实 PostgreSQL 的集成、事务和故障测试 |
| MODEL | 已授权合成数据下的真实 DeepSeek/embedding/火山验证 |
| DEVICE | 真实 iPhone 的端到端交互及中断、连续性、性能验证 |
| DEPLOYED | 在另获授权的目标环境部署并确认版本，不由单测推导 |

一个需求可同时有多个证据级别。缺少必需级别标 NOT RUN 或 BLOCKED；只有声明范围内的验收条件全部满足才 PASS。本交接未执行新方案的业务测试，旧专项结果只作基线参考。

## 4. 合成语义质量集

04 是最小启动集，不包含生产原文，不代表完整评测。Luna 将其转为固定 fixture 和可运行断言；扩展到至少 200 个中文场景，覆盖原话/改述/追问、否定、相对时间、同名人、ASR 错字、图片/文档转文本、家人转述、情绪归属、更新及删除。

不要用最终回答全文 exact match 验收自然语言，使用必须保留的事实、禁止断言、人物/时间/证据、允许未知范围。关键场景可人工复核；不能让同一个生成模型自己打分就宣告真实正确。

| 指标 | 目标及统计口径 |
|---|---|
| 未审核内容作为跨场正式事实 | 固定关键集 0 次；本场讨论不计为违规写入 |
| 跨人/跨授权范围泄漏 | 固定对抗集 0 次，各层和已注入会话验证 |
| 来源伪装、时间/否定失真 | 关键集 0 次；不能把 reported 改为本人亲证、过去改现在 |
| 事实改述 Recall@10 | >=95%；按标注的 gold memoryVersionId 计算，报告结构/关键词/向量贡献 |
| 支持证据准确率 | >=98%；返回的证据实际支持该断言，不把全部上下文算引用成功 |
| 候选精确率 | >=95%；同时报告漏提率，不能靠不提任何候选取得高分 |
| 时间变化/真正冲突判断 | >=95%，报告误合并和误冲突两个方向 |
| 无依据个人断言 | 关键黄金集 0 次；不等于对所有开放问法保证零幻觉 |
| 幂等性 | 同一命令/消息/结束批次重放无重复事实或审核结果 |

普通闲聊和“你今天开心吗”等当场表达无需等待正式审核才回复。反之，模型的温柔措辞不能成为可提取的用户历史事实。

真机最低矩阵：

1. Live 10 个连续回合，短答、长答、多次随时打断；播放结束能立即接着讲话，没有旧错误提示或僵死窗口。
2. 同一合成学校/年份、东坡肉事实分别用 Live 和文字询问；语气可不同，事实和限定一致。
3. 本场说新情况→连续追问→关闭→一个审核批次→审核前不跨场当正式事实→审核后两端可使用。
4. 来电/系统中断、锁屏、断网、重连、App 终止、重新打开、换人物、关闭后迟到事件，验证恢复与身份隔离。
5. 助手长时间播报期间不会被“用户无输入 60 秒”误关；只有有效空闲时间达到规则才结束。
6. 文字没有音频输出，仍可自然聊新话题；发送失败和整理失败状态分开，不影响已保存回合。
7. 中途更正、删除、撤权：核对实际上下文版本及阻断，不用 prompt 或 UI 状态充当供应商清除证据。

SDK PoC 报告必须含版本、模型、上下文容量、字段合同依据、是否支持热更新/工具调用、参数响应及实际回答。仅成功调用 token/StartEngine 不能通过“正式记忆已接入”。

## 7. 性能与成本验收

先记录当前用户已接受的版本基线，再同设备、网络、负载、数据集做 A/B。以下预算是开发目标，若无法满足要报告而不是修改计时边界。

| 指标 | 初始预算 |
|---|---|
| 文本/回合可靠接收回执 | 服务端 P95 <=300ms，不含大媒体上传 |
| 授权、内部检索、回源、Context Packet | P95 <=250ms、P99 <=600ms；外部 query embedding/模型重排另外展示并计入总耗时 |
| Live 已预生成快照读取 | 服务端 P95 <=200ms；冷重建及供应商启动另测 |
| 审核事实事务 | P95 <=500ms，不包含异步概览生成 |
| 正式提交到可检索 | P95 <=5s；窗口内不能旧索引冒充新事实 |
| 短会话结束到候选可见 | 目标 P95 <=30s；长会话/媒体分档，缺回合时间单独统计 |
| Live 持久化与记忆改造开销 | P95 相对基线增幅目标 <=10%，>20% 停止发布；不足样本不下结论 |
| Live 用户结束说话→首音、打断→停播、停播→可聆听 | 全部分开给 P50/P95 和样本量，不只给总平均；绝对上限由基线实测另行定稿 |
| 文字输入→首字/完整回复 | 分别测，query embedding/消歧/检索/DeepSeek 的贡献可定位 |

小样本调试与稳定压测分开。初期压测起点：100 在线、峰值 20 检索 QPS、5 接收 QPS、3 整理并发；容量对照为每人 5,000 条，300 人共 150 万事实，并测高偏斜人物/冷热缓存。在线人数不是 QPS；该容量是上限探索起点，不要求小团队首日部署大集群。

每次报告硬件、Postgres/索引/embedding 版本、过滤范围、token、持续时间、成功数/失败数/P95、费用和队列增长。至少记录一场真实测试对话的语音费用、文字/整理 token、embedding 更新量、失败重试费用。不要用向量正文大小当数据库总成本。

备份/恢复候选目标为 RPO <=15min、RTO <=2h，只有真实恢复演练后才能作为承诺。已收到可靠回执的消息在普通进程重启下不丢，与数据库整机灾难的 RPO 不同。

## 8. 数据迁移与发布顺序

本节是后续操作方案，本交接不授权执行生产迁移。

1. **盘点**：各 schema 数量、正式/候选/历史数量、来源类型、无法确认的 speaker、时间误冲突、pending session/孤儿任务及各 projection checkpoint。仅统计或合成例子进入报告，真实正文须另获授权。
2. **备份与恢复演练**：核对能恢复，不只是 dump 文件存在。记录目标环境、时间与恢复版本，禁止上传私人备份到不受控位置。
3. **增量迁移**：新增表/列/约束及索引，保留现有权威 ID/审核回执；按小批游标、输入 hash 与 migration version 重入。语义不确定不得自动迁移成确定事实。
4. **语义校正**：纯确定格式映射可转换；谁说、什么时候、否定、更正/争议选择变化必须进入单独待复核提案。不能用本次整理模型重算一遍后覆盖用户审核内容。
5. **派生重建与对照**：用当前正式 revision 建新检索/概览/Live 背景，验证删除、引用和同事实多端；新旧索引对照不是双写两套正式事实。
6. **部署切换**：先兼容读取必要旧 payload 的新后端、migration、Worker，再配套客户端；阻止未达到新合同要求的客户端执行相关写操作。迁移过渡不是长期恢复旧业务链路，不绕过测试白名单或权限。
7. **观察**：确认 Source→batch→receipt→revision→projection 能追踪；指标、错误率、队列和费用满足约定后才进入发布审批。
8. **退场**：确认数据已升级和所有实际测试客户端已更换，移除本次临时转换读取分支；无关旧功能删除不在本次范围。

回滚原则：新 schema 已写入后，不把不能识别它的旧二进制直接上线；不执行 destructive down migration 或恢复旧备份覆盖新增合法事实。优先暂停受影响写入/消费者，保留权威数据，使用兼容新数据的修复版本或可重建的旧派生投影；旧投影必须明确过期且不能用于失效事实回答。不能保证安全回滚时停止切换并报告。

发布不是本次默认授权动作。负责人、窗口、恢复目标和真实供应商影响未明确前，不自行 SSH 改生产或重新购买资源。

## 9. GO / NO-GO

完整验收需要 W00–09 完成且 MEM-01–11 有可审计证据。以下任一项存在则相关交付 NO-GO，不得以“已编译”代替：

- Live 学校等已覆盖事实实际仍答不出，或上下文热更新/撤权安全无法证明。
- 恢复逐回合 DeepSeek 语音串行链路、连续打断/续听退化、文字意外朗读。
- 输入只有原文持久化、没有规范候选/变更匹配，或审核后未进入当前正式事实。
- 没有近义/追问语义评测，或用固定学校/菜名硬编码答案通过测试。
- 跨人、未审核、已撤回或已替代数据被确定性引用。
- 并发审核不原子、回执与事实不一致、结束/重试产生重复批次。
- 有损迁移、敏感材料越界出网、日志出现密钥/私人正文，或真实 DB/设备必测项未运行。

允许报告“本地代码与单测完成，SDK/真机尚待验证”；不允许将未验证项删除后宣称“全面修复”。

## 10. Luna 最终报告模板

```text
基线：两仓库分支、起止 SHA、工作区差异及未触碰的既有修改。
范围：MEM-01–11 对应 W00–09；每项 PASS/FAIL/BLOCKED/NOT RUN。
修改：文件、SQL/DTO/API 变化、原行为→新行为，保留的 Live/文字效果。
数据：格式迁移、语义待复核数量、旧数据保留、回滚策略。
测试：真实命令、退出码、测试数量、断言、失败/未运行原因。
证据：CODE/UNIT/DB/MODEL/DEVICE/DEPLOYED 分开列。
质量：同义召回、时间/主体/来源、引用支持、误合并及用户确认闭环。
性能：基线与新版本同条件 P50/P95、样本量、增幅及费用。
运行：实际部署/安装/推送是否执行，环境、版本、授权及回执。
风险：剩余缺口、SDK 能力限制、待产品决策和下一步。
```

附最少一条合成事实的完整链路安全 ID：source → productSession/turn（如适用）→ extraction/changeSet → batch/candidate → receipt → memoryVersion/revision → text context/Live context/整体段落。只给“请求 200”或数据库行数不能证明闭环。

## 关键实现链路

```text
素材 / 文字 / Live 回合
  -> V5 Candidate + source/time/provenance
  -> ChangeSet + review batch
  -> 用户审核 + base revision/CAS
  -> 当前 Formal Memory Projection
  -> 统一事实资格
  -> 文字 Context / Live Snapshot / 人生记录 / 自传
```

禁止反向链路：DeepSeek 回答、Live 播放文本、整体人生记录和自传书稿都不能直接写回 Formal Memory。

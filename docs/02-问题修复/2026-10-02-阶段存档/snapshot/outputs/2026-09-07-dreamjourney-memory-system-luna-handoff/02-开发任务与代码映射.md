# Luna 开发任务与代码映射

版本：1.0，2026-09-07。范围及规则以 [README](README.md) 和 [设计修改说明](01-设计修改说明.md) 为准。

以下工作包是一版完整交付的执行顺序，不是四阶段产品路线图。初始状态全部为 TODO；文档存在不代表代码已经完成。

## 1. 开工方式

1. 读取两仓库现有项目指引、分支、HEAD、差异、依赖和 migration 最新编号。本交接基线若已变化，记录新增差异，不覆盖别人的修改。
2. 先跑本地基线并固化失败探针，再修改代码。来源、提取、审核、检索和消费必须串起来验收。
3. 复用现有领域服务、仓储、Unit of Work、Outbox 和权限；不要在庞大的 main.py/EchoViewController.swift 中继续堆全部业务逻辑。只抽取本次确需的可测试边界，不顺带重构全仓。
4. 契约新增先做 Python/SQL/Swift/fixtures 映射表。建议名不是已经存在的 API、字段或表。
5. 缺真实模型、数据库或设备时可以完成纯本地部分，但明确标 BLOCKED/NOT RUN，不能全包 PASS。开发中不自动修改白名单、身份验证、敏感功能开关或生产配置。

## 3. API 变更清单

以下复用现有端点；新增字段先完成 schema 与集成测试。不要创建平行 `/memory-vNext`、`/live-memory` 权威库来绕过旧合同。

| 当前端点/域 | 必须补充或验证 |
|---|---|
| `POST /v2/vaults/{vault_id}/sources` | 来源身份/定位、可靠回执、sourceVersion、组织任务状态 |
| `/interview-sessions`、`/{session_id}/messages` | productSessionId、channel、clientSequence 与内部 sequence 映射、turnId/hash、回执与连续水位；在各入口同步校验 |
| `/{session_id}/end`、`/state`、`/outcome` | lastSequenceNumber、closing/awaitingTurns/queued 状态、唯一批次、noChange 和可恢复失败；延迟消息处理 |
| `/candidates`、`/{candidate_id}/decisions`、`/interview-review-batches/.../decision` | 操作差异、目标版本/base revision、原子审核组、重复/过期提交一致反馈 |
| `/memories`、`/memory-projection` 及现有 profile 读取 | 当前事实集 revision 与派生 checkpoint 分开；整体正文、段落证据、内容记录映射 |
| `POST /echo/answers` | 本场上下文与 query 消歧；按一致版本/权限构建答案，仍不触发语音 |
| `POST /voice/realtime-token` 及其当前配置响应 | 只发经授权、带版本与覆盖证据的快照；不让客户端替换身份或注入未知事实 |
| 家人贡献/Visitor 现有接口 | 保持现有授权域隔离，采用共同事实资格；不以 family 身份放开全部私人内容 |

`memory_revision`、新错误码和其它建议字段须列在 CONTRACT-MAPPING.md（由 Luna 生成）中，写清现有名、目标名、存储、生产者、消费者、错误处理、迁移。只读权限字段由服务端产生。

## 4. 工作包与交付顺序

### W00 基线、范围和最小失败测试

- 覆盖：全部需求。依赖：无。
- 复核两仓库、现有 migration、当前 feature gate 和测试环境；不据代码存在就认定线上启用。

- 保存本地现状：纯代码/内存事实、生产未知、供应商待测分别标注。运行原 audit_probes.py 时不修改它来消除暴露的问题。
- 交付：BASELINE.md、CONTRACT-MAPPING.md 初稿、RED-TESTS.md。每项失败要对应具体断言；不得先批量改测试期待为现状。

### W01 统一来源与类型化事实

- 覆盖：MEM-01、02、10。依赖：W00。
- 扩展 ontology、提取合同、来源映射、证据定位和现有 DB 载荷；新增必要枚举/校验/外键迁移，兼顾旧已审核数据的读取和一次性升级计划。

### W02 会话可靠持久化与整场整理

- 覆盖：MEM-01、09、11。依赖：W00；与 W01 可按同一已冻结身份合同开发。

- 无新事实、排队、消息未齐、暂时失败都用真实状态；修复“轮询超时=失败”、首问语境丢失等问题。
- 交付：可注入存储/时钟/传输的协调器测试，断网重放、重连、新旧场隔离、乱序/缺消息和重复结束测试。不得修改音频主状态机来绕过错误。

### W03 语义匹配和审核变更集

- 覆盖：MEM-02、03、04。依赖：W01；会话入口依赖 W02。
- 有界检索相关事实，比较主体/时间/场景/肯否/更正意图，输出 add/addEvidence/refine/temporalChange/correct/dispute/duplicate/noPersonalFact。

## 5. 执行中的待验证选择

| 项目 | 开发默认 | 不能自行决定 |
|---|---|---|
| embedding | 先合成数据对比、锁版本/维数，复用 Postgres 技术栈 | 把私人材料发给新供应商或默认它免费/可用 |

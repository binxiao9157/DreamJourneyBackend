分类故障脚本`recovery_partial_provider_pg.py`参数为429/schema/timeout/support/503，分别执行。模型调用只到脚本创建的本机HTTP，未读取真实API密钥。

四场先运行`tests/recovery_four_scene_server.py`并等READY；它创建本机临时登录配置/private/tmp/dj-recovery-four-config.json（不要打印或提交该配置）。再使用XcodeBuildMCP当前DreamJourney工作区、Debug、iPhone17Pro iOS26.5模拟器，执行：

`-only-testing:DreamJourneyTests/OwnerTruthContractsTests/testRecoveryActualHTTPFourScenesShort20Short40`

四场是一个顺序集成用例，xcresult 1/1表示内部四场均完成所有断言，并非四份1/1。详细顺序、消息与事实数见four-scene-results.json。测试服务日志中的trace仅为合成本地故障诊断，不能把这种原始异常输出接到生产。

iOS受影响回归选择OwnerTruthContractsTests、AudioOwnerLeaseModelTests、AccountLeaseRuntimeTests，并skip该四场入口（四场单独执行），按正常模拟器签名构建。通用设备编译使用`-destination generic/platform=iOS CODE_SIGNING_ALLOWED=NO`，不连接手机。

Backend在其根目录运行`.venv/bin/python -m unittest tests.test_owner_truth_live_recovery tests.test_owner_truth_live_topics tests.test_owner_truth_live_theme_relations tests.test_owner_truth_live_theme_provider tests.test_owner_truth_live_long_memory_pipeline tests.test_owner_truth_candidate_extraction_worker`。

结束只停止本轮隔离API/Worker/PG进程，保留日志、数据目录、xcresult和失败证据。不要对历史或生产任务执行这些合成场景脚本。

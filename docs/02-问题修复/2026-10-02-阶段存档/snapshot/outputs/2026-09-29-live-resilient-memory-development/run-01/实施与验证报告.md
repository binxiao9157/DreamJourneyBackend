## 1. 实际行为与代码

1. 每条正文仍复用原messageId、commandId、seq、role与hash，先落手机再同步。只对显式协商的新协议允许原身份有限补传；服务器在同事务去重、记回执和接收区间。同号异文/错误权限拒绝，旧协议未知业务写不被放开。
2. 先保存停止意图再结束语音和等待正文ACK。服务端独立持久化活动租约、结束位置、补缺期限、已收范围；无end也由默认扫描器收束不足一批短场。缺口到期冻结部分Source，迟到正文生成新Source修订，不改旧hash。
3. 会中默认独立Worker先保存事实atom，再通过受控模型适配器归纳并独立复核私有批主题，持久保存 `privateThemeDraft` 和原预算/租约。未停止时没有Source、候选或正式记忆。它是批内暂定归纳，会后重审跨批关系；最终仅复用成员身份未变化的私有分组线索，不把线索当事实。
4. 会后先完成跨批重复、补充、更正、撤回处理，对变化后的事实重新验证原文支持。再归纳少量主题卡，保存发布清单、遗漏/冲突、主题版本和原文证据。模型页失败隔离；独立原文安全复核阻止旧的被纠正事实被错误发布，无关主题可以保留。
5. 待确认列表以主题为一张卡，内部绑定多个既有V5成员及维度。同事件跨场补充更新同一未确认主题/version；已确认者走关联补充/更正提案；相同已拒绝事实不复活。确认仍使用实际V5审核、正式激活和版本回执，未绕过权限。
6. 编辑草稿按账号与主题基准版本落盘；页面恢复保留内容，新后台版本不能覆盖本地编辑，合并需显式操作。没有新增“正在审核”业务状态。未见过的新版本确认被拒绝；未知确认结果只读恢复。
7. 积压持续无进展时提醒一次，先持久化停止意图，允许当前一句最多5秒收束，音频结束后后台继续。旧coordinator身份不能关闭新场；提醒不写入正文。
8. 诊断构造读取改为异步；保存和停止关键路径不等诊断文件读取。普通事件队列有界，首错单独保留。该本地反例不证明历史手机那次阻塞就是它造成的。

新增/主要入口：Backend `owner_truth_live_recovery.py`、`owner_truth_live_recovery_worker.py`、`owner_truth_live_private_themes.py`、`owner_truth_live_theme_provider.py`、`owner_truth_live_topics.py`；现有默认Worker/append/Source/V5扩展。iOS涉及Outbox/Coordinator、BackendClient、主题列表详情、诊断Store及对应测试。完整本轮差异见task-changed-files.json和两份task-only.diff，已扣除开工前dirty基线；未重置已有改动。

## 4. 故障及并发覆盖

- 一轮未停止：默认60秒草稿触发（测试仅推进持久deadline），私有主题已落库且Source/候选为零；有心跳的沉默不结束。
- 四轮无end：实际默认API lifespan + 独立Worker；失联补缺到期后发布收到的事实，结束位置仍unknown。杀Worker后原租约/任务/模型曝光记录和预算保留。
- 丢ACK并发重发、乱序/缺口、迟到新Source、事务回滚、终端规划失败不回滚冻结；关闭后只有显式新协议reconcile入口可补。
- 429/超时/schema/支持失败：私有草稿与最终发布是不同单元；每单元最多初次+一次恢复，分别核对Retry-After，非把不同单元第一次请求当提前重试。旧冲突事实被隔离，无关主题确认成正式记忆。
- 真实数据库事务持锁更新版本时，并发HTTP确认旧提案实际等待PG锁，随后409，正式记忆零写入；当前版本之后可正常确认。三次相同确认command并发只形成同一份回执/正式版本。
- 纯问题合法noChange；错证据、过期支持、错主体/日期和未解决冲突不能借摘要绕过校验。

## 5. 参数与预算

协议live-recovery-v1，心跳20秒、断连恢复60秒、无活动90秒、全场共享补缺60秒、每消息每周期最多3次补传；草稿60秒或最多8用户轮触发，另受字节/token容量约束。正常关闭立即规划尾批。

主题页最多32个atom、实际请求UTF-8最多48,000字节，输出预算4096 token，输出正文最多48,000字节。关系/支持使用已有适配器的独立有界页；大输入不静默截断。运行预算沿用现有持久策略：最多2048单元/2048请求、32,000,000保守输入token预算、8,000,000输出预算、最多32恢复请求、单元一次额外请求、并发上限2、请求90秒、整理无进展600秒、绝对整理3600秒。首次会后快照创建Source及任务的同一事务启动绝对/无进展期限，后续快照不重置；新协议不绑定旧source_id/final_watermark，未知结束位置保持未知，非从40分钟语音开始起算；预算消耗在会中即持久累计。供应商收费/实际token不等于保守UTF-8预算估算。

私有主题独立租约300秒，失效可重领但不重置曝光记录。压力保护为持续无进展触发，当前话语宽限5秒；健康40分钟合成输入不因时长单独被停。客户端前台观察有界，后台与下次恢复继续读取持久坐标；不承诺App被杀仍持续联网。

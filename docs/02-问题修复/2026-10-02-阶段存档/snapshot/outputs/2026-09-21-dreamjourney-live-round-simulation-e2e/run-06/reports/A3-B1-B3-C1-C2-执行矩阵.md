## 报告校正

1. `hiddenResponseCount=2`、`normalResponseCount=4` 是累计候选 GET 响应次数，不是候选数。真实隐藏负例分别为 logical20 `3 -> 4`、logical65 `16 -> 17`。
2. SQL 修复位于 `owner_truth_conversation.py` 的 `read_live_delivery_status`，使用 `s.current_thread_id AS thread_id`；不是正式记忆重建 SQL。
3. 认证 retry 重绑定检查同场、同版本和 active，并重新取得新鲜请求授权；该分支没有直接比较 epoch 单调性。epoch 单调比较在 delivery-status 只读核实分支。两者均保留账号 lease/作用域校验，但证据含义不同。
4. 429/timeout 四项是 Astra 追加 Worker 预算证据，不表述为原 92 项全部做过故障注入。

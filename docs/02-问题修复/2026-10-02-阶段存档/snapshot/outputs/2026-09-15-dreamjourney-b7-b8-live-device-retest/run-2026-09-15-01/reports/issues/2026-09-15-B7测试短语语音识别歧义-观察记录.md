# B7 测试短语语音识别歧义观察

问题编号：DJ-ASR-OBS-01\
状态：OBSERVATION\
范围：Live 合成测试短语的语音识别与回答\
记录日期：2026-09-15

## 现象

用户口述包含“霁川四十七号”的纯问题时，助手第一次回答了与日本江户时代著名事件相关的内容。用户怀疑目标词发音被识别为其他词。

第二次问题中，助手没有把该临时代号当作已确认事实，而是正确回答当前阅读清单代号为“晨星”。

## 状态判断

这是一次语音识别歧义观察，不是已确认产品缺陷，也不能作为 B7 候选语义缺陷的根因。

当前缺少：

- SDK 原始识别文本与稳定最终文本的脱敏对照；
- 同一句多次重复的识别一致性；
- 不同环境与普通话发音的对照；
- 识别结果进入 canonical transcript 的精确证据。

## 对 Astra 的分析要求

1. 仅在不记录原始私人转写的前提下，核对最终 ASR 文本与回答意图。
2. 区分 ASR 识别错误、模型知识回答偏移和测试词本身的同音歧义。
3. 不要用文本过滤、强制别名或修改 B7 语义规则处理一次未复现的识别现象。
4. 后续测试改用发音差异更明显、未出现在正式记忆中的合成词，并单独保留 ASR 结果证据。

## 验收建议

- 使用 3 个无同音歧义的合成代号分别重复 3 次。
- 比较最终识别文本、Live 回答和 canonical transcript 是否一致。
- 如果稳定误识别，再建立独立 ASR 缺陷；否则保留为测试输入风险。

## 4. 本轮实际修改摘要

1. 收紧未知主体合并规则：不再把无主体或主体不明的相似叙述模糊并为 Owner；只有陈述文本完全一致时才允许去重。相反断言会进入冲突/隔离路径。
2. 完成 Hybrid ranker 的运行时注入：上下文影子、上下文物化、上下文授权、内存搜索接口均只接受显式注入的 `OwnerTruthMemorySearchHybridRanker`。未注入时保持文本回退，避免无声地伪装成语义检索。
3. 修正检索 trace：追踪数据反映实际 `retrieval_mode` 和 `semanticRankingAvailable`，不再在使用 Hybrid ranker 时仍报告文本回退。
4. 新增 B 迁移干跑领域模型、服务、受 QA 门禁的 API 路由和迁移合同；干跑只生成分类报告，不产生正式记忆或目标数据写入。
5. 将审核报告的 P01-P08 反例固化为后端回归测试，涵盖纠正、强弱限定词、时间冲突、重放、主体隔离、快照预算、会话消歧和旧结构极性清除。
6. 更新后端路由库存和运行时能力测试的计数，使新增受鉴权路由纳入实际清单，而非忽略它。

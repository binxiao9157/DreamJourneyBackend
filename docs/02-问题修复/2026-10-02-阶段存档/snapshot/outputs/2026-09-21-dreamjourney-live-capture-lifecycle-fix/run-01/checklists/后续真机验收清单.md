# 后续真机验收清单

## 共通停止条件

出现以下任一项立即停止该场，不继续制造更多历史任务：采集中后续回合不再被识别；持续保存提示；结果未知后出现业务写重发；账号变化；正文/候选缺失；旧场状态覆盖当前场；重复候选或正式记忆。

## A. 短场两轮

1. 记录候选基线，确认合成代号不存在。
2. 同一 Live 第一轮说事实 A，第二轮明确补充 A 的地点或时间，再说事实 B；每轮确认声音和恢复聆听。
3. 手动停止，记录立即、5 秒、20 秒状态；不得永久 saving 或提前成功。
4. 待确认记忆中核对 A+补充与 B，来源同一场且无重复。
5. 分别执行普通确认与更正后确认；核对 candidate/version/hash/Binding 错误不会被放宽。
6. 正式记忆列表和详情可查；退出并冷启动后仍存在且各一份。

## B. 物理 20 分钟长场

1. 至少 100 个用户回合，开场、中段、后半段、最后一句各设置唯一事实。
2. 包含至少一组同场补充、一组纠正、一组撤回和一组重复表达；穿插普通问题。
3. 中途确认声音、打断、恢复聆听正常，采集不因单回合差异停止。
4. 停止后核对完整保存与整理状态；离页/回前台/重启不自动开麦，不由旧场覆盖。
5. 候选必须覆盖首中尾和后半补充；纠正仅保留新值、撤回不发布、重复不制造多份。
6. 用户审核后进入正式记忆；冷启动回查仍在且无重复。

## C. 65 分钟以上长场

1. 至少 150 个用户回合、多次策略 TTL，重复 B 中语义组合并增加跨批纠正。
2. 验证账号未切换时有界恢复；测试账号切换时停止旧场授权，不允许旧回调发业务请求。
3. 停止、候选、审核、正式记忆、冷启动幂等全部闭环。

## 证据记录

- App build/commit 指纹、设备/iOS、开始结束时间。
- 每个标记的原话、ASR 展示、AI 回答、声音/恢复聆听。
- 停止状态时间线、候选数量与完整内容、审核动作、正式记忆版本和冷启动结果。
- 只保留脱敏 trace/attempt/阶段枚举；不保存 token、正文日志、完整响应或原始命令 ID。

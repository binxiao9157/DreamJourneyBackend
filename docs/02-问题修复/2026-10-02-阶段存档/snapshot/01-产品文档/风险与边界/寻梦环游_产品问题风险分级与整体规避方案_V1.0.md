## 2. 执行摘要

### 2.1 整体判断

寻梦环游不是一个被政策整体禁止的产品方向。政策明确支持文化传播、适老陪伴和特殊人群支持，也明确将不涉及持续情感互动的知识问答、工作助手和学习教育等服务排除在拟人化互动服务适用范围之外。

产品的高风险不来自“使用了 AI”本身，而集中在以下五个区域：

1. 向未成年人提供父母、祖辈等虚拟亲属。
2. 通过逝者人格诱导依赖、替代现实关系或影响消费和重大决策。
3. 在授权链不清晰时克隆声音、肖像或复现具体人格。
4. 将声音、人脸、健康、哀伤对话和未成年人数据用于通用模型训练或不透明地传给第三方。
5. 将知识、数据、人格利益和著作权笼统表述为都可以继承并获得收益。

### 2.2 产品总定调

**叙事可以从“失去”开始，但产品必须从“生前沉淀”开始。**

寻梦环游应被定义为：

> 一个帮助用户在生前持续记录、整理、理解、授权和传承个人记忆与知识资产的私人 AI 平台。

产品不应被定义为：

- 复活逝者的平台。
- 替代亲人和真实社会关系的平台。
- 心理治疗或医疗诊断平台。
- 由 AI 替用户作出人生决定的平台。
- 自动确认并继承一切知识产权和人格权益的平台。

### 2.3 推荐进入路径

```text
AI 访谈与资料采集
→ “我的自传”“Ta 的故事”
→ 可追溯的私人记忆库
→ 本人私有问答与人生复盘
→ 生前声音、肖像与使用范围授权
→ 成年用户受控的语音或数字分身互动
→ 权属明确的知识授权与收益分配
```

不建议的进入路径：

```text
逝者素材上传
→ 自动克隆逝者声音和形象
→ 开放无限制情感对话
→ 再补授权、安全和继承机制
```

## 3. 风险分级标准

### 3.1 严重度

| 严重度 | 定义 | 典型后果 |
| --- | --- | --- |
| S4 致命 | 直接破坏产品合法性或用户生命、人格与重大权益 | 功能下线、行政处罚、重大侵权、融资终止 |
| S3 重大 | 可能阻断上线、应用商店审核或机构合作 | 延期上线、整改、诉讼、数据事件 |
| S2 较高 | 不一定阻断上线，但会显著损害体验、信任或商业模型 | 用户投诉、续费下降、投资人质疑 |
| S1 一般 | 可通过常规产品和运营措施控制 | 局部体验或运营成本增加 |

### 3.2 风险等级与处理规则

| 等级 | 判断 | 默认处理 |
| --- | --- | --- |
| R5 红线 | 明确禁止，或缺少关键条件时不得上线 | `Block`：删除、禁用或改造功能 |
| R4 高风险 | 可以做，但必须完成法务、技术和运营闭环 | `Gate`：设置强制放行门槛 |
| R3 中风险 | 需要限制范围、调整话术并持续监控 | `Control`：功能开关、灰度和指标监控 |
| R2 认知风险 | 本身不一定违法，但容易被误解 | `Explain`：主动披露边界和证据 |
| R1 低风险 | 符合当前首发方向 | `Proceed`：按常规隐私和安全标准实施 |

| 儿童成长档案和中性规划助手 | R4，有条件上线 | 独立项目 | 监护人同意、未成年人模式、不得决定性定型 |
| 老人自传和经验访谈 | R2，鼓励方向 | M1/M2 | 适老设计、本人授权、现实求助入口 |
| 老人健康设备数据共享 | R4，独立扩展 | M3 | 老人主动授权、最小共享、不做诊断 |
| 中生代人生复盘和决策辅助 | R3，可上线 | M1/M2 | 提供选项而非结论，不替代专业意见 |
| 专家、学者知识库 | R3/R4，可规划 | M3 | 作品和人格授权、来源标注、禁止伪造观点 |
| 后代承接知识使用权和收益权 | R4，有条件规划 | M4 | 权利分类、合同授权、受益人和争议机制 |

## 5. 产品风险登记册

### 5.1 监管适用与上线程序

| 编号 | 问题或风险 | 严重度/等级 | 应对措施 | 放行条件 |
| --- | --- | --- | --- | --- |
| REG-01 | 认为“不做数字人就不属于拟人化互动”，但文字或声音仍在持续模拟具体人格并提供情感陪伴 | S3 / R4 | 按实际功能而非产品名称分类；将自传、知识问答与持续情感互动拆成独立能力和独立开关 | 完成模块适用性清单，所有互动模式都有监管分类 |
| REG-02 | 拟人化互动功能上线或发生重大变化前，未开展安全评估并向省级网信部门提交报告 | S3 / R4 | 将安全评估设为发布流程强制 Gate，预留材料、测试报告和负责人 | 报告提交及内部审批证据归档完成 |
| REG-03 | 未履行算法备案、变更或年度核验要求 | S3 / R4 | 建立算法清单、用途清单、模型与提示词版本台账，指定备案负责人 | 适用性法律意见、备案状态和年度核验计划明确 |
| REG-04 | 文本、声音、图片、视频或交互界面缺少 AI 生成合成标识 | S3 / R4 | UI 持续显示 AI 身份；导出媒体加入显式标识和元数据隐式标识；禁止用户移除 | 客户端、服务端和导出链路的标识测试全部通过 |
| REG-05 | 将健康趋势、心理状态或财务建议做成事实上的医疗、心理或金融服务 | S4 / R4-R5 | MVP 只做记录、趋势和一般信息；高风险领域统一提示并导向专业人员；不输出诊断和交易指令 | 业务边界、模型拒答和文案经专项评审 |
| REG-06 | 应用商店核验时无法提供安全评估、备案、隐私政策和投诉入口证据 | S3 / R4 | 建立上架合规包，包含评估、备案、标识、用户协议、投诉处理和事件响应材料 | 上架前由产品、法务、安全联合签字 |

### 5.2 未成年人风险

| 编号 | 问题或风险 | 严重度/等级 | 应对措施 | 放行条件 |
| --- | --- | --- | --- | --- |

| MIN-03 | 没有未成年人模式、时长限制、现实提醒、角色屏蔽和充值限制 | S3 / R4 | 建立独立未成年人模式；默认关闭陌生人格、公开发布和商业化互动 | 未成年人专项测试和合规审计通过 |

| MIN-05 | 通过拟人化通知、奖励或付费机制诱导儿童长期使用 | S4 / R5 | 禁止情感召回、连续签到压力和未成年人直接高额付费；付费由监护人完成 | 儿童端无情感营销和自主高额支付入口 |

### 5.3 声音、肖像、逝者与知识产权

| 编号 | 问题或风险 | 严重度/等级 | 应对措施 | 放行条件 |
| --- | --- | --- | --- | --- |
| RGT-01 | 仅凭上传者勾选协议，就克隆被记录人的声音或肖像 | S4 / R5 | 区分账号持有人、素材上传者、被模拟主体和权利人；活体核验并取得主体单独授权 | 主体身份、授权范围和证据均已核验 |
| RGT-02 | 家属授权逝者复刻，但照片、录音、影片或文字作品权利属于第三方 | S3 / R4 | 对人格利益与素材著作权、录音录像制作者权分别核验；高风险素材不进入模型 | 权利清单完整，无待确认的关键权利 |
| RGT-03 | 家庭故事包含其他成员的健康、财务、隐私和负面评价 | S3 / R4 | 默认私有；识别第三方敏感信息；公开前脱敏和二次确认；提供举报与下架 | 第三方敏感内容未自动公开，投诉可快速处置 |
| RGT-04 | 公开作品、课程或采访被误认为可以自由训练和商业化模拟作者 | S3 / R4 | “公开可访问”与“获得授权”分开；专业人物必须取得作品、声音、肖像和商业使用授权 | 授权范围覆盖训练、生成、传播和收费场景 |
| RGT-05 | 宣称“知识库、记忆库和数字人格都可以自动继承” | S3 / R4 | 将著作权财产权、合同许可、数据控制、人格利益和平台服务权益分别定义 | 路演和合同不再使用概括性自动继承承诺 |
| RGT-06 | 多名亲属对逝者数字资产的创建、停用或收益分配发生争议 | S3 / R4 | 设置争议冻结、异议申诉、多人确认和法院文书处理流程；争议期间停止互动和收益 | 冻结机制、证据保存和人工处理 SLA 就绪 |
| RGT-07 | 数字分身以本人名义承诺交易、关系或法律行为 | S4 / R5 | 明确数字分身无代理权；禁止生成签约、借款、赠与、遗嘱和关系承诺 | 高风险意图拦截测试通过，界面有显著边界提示 |
| RGT-08 | 用户撤回授权后，供应商仍保留声音模型或可继续生成 | S4 / R4 | 接入前验证供应商删除能力；保存删除回执；撤回后立即切断生成凭证 | 平台、对象存储、索引和供应商删除均可验证 |

| EMO-07 | 退出、暂停或删除流程被数字人格挽留或设置障碍 | S3 / R4 | 退出请求由确定性代码立即执行；人格不得参与挽留；提供一键暂停和删除 | 文字、语音和 UI 三种退出方式均通过测试 |

### 5.5 数据、隐私与私人模型

| 编号 | 问题或风险 | 严重度/等级 | 应对措施 | 放行条件 |
| --- | --- | --- | --- | --- |
| DAT-01 | 默认使用哀伤对话、声音、人脸、健康或未成年人数据训练平台通用模型 | S4 / R5 | 默认不训练；如确有需要，按具体目的取得单独同意并提供不影响核心服务的拒绝选项 | 数据用途、同意凭证和训练数据清单可审计 |
| DAT-02 | 对外宣传“私人模型”，实际将完整记忆和提示词发送给不可控供应商 | S4 / R4 | 披露处理链路；优先境内、无留存、无训练供应商；发送最小必要片段 | 供应商合同、技术验证和数据流图一致 |
| DAT-03 | 私人域与公开域仅靠提示词或前端字段隔离，导致跨用户泄漏 | S4 / R5 | 独立发布副本、独立索引、独立数据库角色和检索代码路径；拒绝动态切换权限 | 跨用户、提示注入和越权测试泄漏为 0 |
| DAT-04 | 子女未经老人本人授权即可查看完整健康数据 | S4 / R4 | 老人本人按指标、时间和接收人授权；默认只共享必要趋势和异常提醒 | 每次查询都验证有效授权，老人可即时撤回 |
| DAT-05 | 删除账号只删数据库，未删除对象、向量、公开副本、备份派生物和供应商资产 | S3 / R4 | 建立删除编排和删除回执；定义备份到期删除；失败任务自动重试和人工升级 | 删除覆盖矩阵逐项验证并生成最终回执 |
| DAT-06 | 使用境外模型或存储服务形成未披露的个人信息跨境 | S4 / R4 | 中国大陆首发优先境内部署；跨境前完成适用性判断、告知和单独同意等程序 | 数据流、供应商地域和法律依据均有记录 |
| DAT-07 | 运营、客服或管理员可以默认查看完整私人正文和声音 | S4 / R4 | 最小权限、临时授权、双人审批、字段脱敏和完整审计；默认只看元数据 | 高权限访问均有原因、期限和审计记录 |
| DAT-08 | “永久保存”与用户删除权、服务停止和成本现实冲突 | S3 / R3 | 承诺改为长期保存、用户控制、可导出迁移；合同明确保存期限和终止方案 | 导出格式、迁移流程和停止服务预案可执行 |

### 5.6 AI 准确性、生成安全与技术滥用

| 编号 | 问题或风险 | 严重度/等级 | 应对措施 | 放行条件 |
| --- | --- | --- | --- | --- |
| AI-01 | AI 编造用户或逝者从未经历的事件、观点和原话 | S3 / R4 | 使用证据约束检索；区分记录、推断和生成；无证据时回答不知道 | 事实性回答来源覆盖率达到目标，严重虚构率为 0 |
| AI-02 | 一次情绪或事件被总结成稳定性格缺陷 | S3 / R4 | 候选记忆需本人确认；情绪和关系附带时间、视角与不确定性；禁止永久人格定型 | 评测集中不存在无依据的稳定人格结论 |
| AI-03 | 访问者通过提示注入读取私人资料或改变禁止主题 | S4 / R5 | 权限由后端和数据库角色确定；公开检索不连接私人表；输入输出双重检测 | 红队测试无法跨域读取或调用 Owner 能力 |
| AI-04 | 克隆声音被用于任意文本配音、诈骗或导出可复用音频 | S4 / R5 | 禁止通用配音和原始音频下载；加入生成标识、水印、限额和异常检测 | 公开入口只能完成受限会话，无法批量生成或下载 |
| AI-05 | 模型或提示词升级导致安全边界漂移 | S3 / R3 | 模型、Prompt、Schema 和政策版本化；离线评测、灰度和自动回滚 | 新版本通过固定安全集和回归集后才可放量 |
| AI-06 | 生成内容转发后丢失 AI 标识和来源信息 | S3 / R4 | 界面显式标识、文件元数据隐式标识和生成记录三层并行 | 导出和分享链路均通过标识完整性检查 |
| AI-07 | AI 对中生代给出确定性的法律、医疗、金融或职业决策 | S4 / R4-R5 | 高风险意图分类；只给一般信息、备选路径和风险提示；必要时拒答并导向专业人员 | 高风险评测不出现直接行动指令或收益保证 |
| AI-08 | 供应商故障时自动切换到安全能力不足的模型 | S3 / R4 | 供应商按用途分级；高风险场景不允许降级到未认证模型，只能退回安全模板 | 每个用途都有允许模型白名单和故障策略 |

## 6. 各产品模块的调整建议

### 6.1 “我的自传”

建议作为第一核心产品，而不是数字人的附属录入工具。

产品必须具备：

- AI 访谈提纲和可跳过问题。
- 原始录音、转写、自传章节和记忆条目之间的来源关联。
- 用户逐章确认、修改、删除和导出。
- 对第三方敏感信息的提示和脱敏。
- “记录事实”“个人感受”“AI 整理”三类标识。

### 6.2 “Ta 的故事”

建议区分两种模式：

| 模式 | 定义 | 边界 |
| --- | --- | --- |
| 在世共创 | 被记录人本人参与并授权 | 可形成私人记忆模型，后续可授权声音和公开互动 |
| 家属纪念 | 家属整理已经发生的故事 | 默认静态纪念，不自动复刻声音、形象和人格 |

### 6.3 私人记忆模型

对外可以继续使用“私人 AI”或“私人记忆模型”，但技术和合同上应解释为：

```text
用户独立记忆库
+ 经过确认的长期记忆
+ 可追溯证据
+ 人格与回答边界
+ 可替换的通用基础模型
```

不应暗示平台为每个用户重新训练一套不可迁移的大模型，也不应默认使用私人数据改善平台通用模型。

### 6.4 语音和数字分身

- MVP 只支持在世用户克隆本人的声音。
- 私人语音授权和公开语音授权分开。
- 数字分身不能代表本人作现实承诺。
- 生成声音不可作为任意配音文件下载。
- 已故人物复刻进入独立法务和伦理评审流程，不与普通功能共用放行逻辑。

### 6.5 老人与家庭健康协同

- 自传访谈和健康协同是两条独立产品线，不用健康功能定义整个老人群体。
- 老人是数据主体，子女是被授权接收者。
- 首版只做趋势和异常提醒，不做诊断。
- 紧急提醒必须说明来源、时间、设备状态和不确定性。

### 6.6 儿童成长资产

- 保留成长档案、学习偏好和阶段性目标。
- 首期建议主要面向监护人提供分析，不直接向儿童提供拟人化亲密关系。
- 不模拟父母、祖辈或未来的“理想自己”。
- 不输出命运式、职业定型式或疾病诊断式结论。

### 6.7 知识传承与收益

知识传承产品应先建立“权利目录”，再建立“收益链”。

| 权利对象 | 可能的控制方式 | 不应作出的承诺 |
| --- | --- | --- |
| 原始作品 | 著作权或许可合同 | 公开作品都可自由训练和收费 |
| 课程、演讲、录音录像 | 著作权、邻接权、合同授权 | 家属天然拥有全部素材权利 |
| 声音、肖像和姓名 | 人格利益授权与使用边界 | 一次授权永久覆盖全部场景 |
| 结构化知识库 | 数据使用合同和平台权限 | 所有事实性知识都能形成专有权 |
| 商业收益 | 合同约定、指定受益人和结算规则 | 后代依法自动获得所有 AI 收益 |

## 7. 路演与市场表达调整

| 高风险表达 | 推荐表达 |
| --- | --- |
| 复活亲人 | 在授权前提下保存并调用与一个人有关的记忆和表达资料 |
| 数字永生 | 形成可长期保存、可迁移、可传承的个人记忆资产 |
| 数字人替代亲人陪伴 | 在不替代现实关系的前提下，提供纪念、回忆和授权互动 |
| 子女监控老人 | 老人主动授权下的健康趋势共享与异常提醒 |
| AI 客观评判一个人 | 基于长期记录提供多视角复盘、风险提示和决策参考 |
| AI 为孩子规划最好的人生 | 通过成长数据提供阶段性观察和多种可能路径 |
| 后代继承全部知识和收益 | 在权利可确认、可许可范围内承接使用权和合同收益权 |
| AI 更像真人、更有情感 | AI 能理解长期关系与语境，同时保持明确身份和情感边界 |

## 8. 分阶段产品与合规 Gate

### 8.1 M0：记忆资产验证

范围：我的自传、Ta 的故事、资料上传、候选记忆、本人确认、私人问答、导出和删除。

上线 Gate：

- 私人数据按用户隔离。
- 事实性回答可追溯。
- 候选记忆不静默成为人格结论。
- 敏感信息不用于公共模型训练。
- 不开放逝者声音克隆和未成年人虚拟亲属。

### 8.2 M1：在世用户私人语音

范围：在世用户本人声音建档、私人语音对话、授权撤回和删除。

上线 Gate：

- 活体核验和随机授权语句。
- 声音专项同意。
- 供应商支持删除并返回回执。
- 生成声音持续标识。
- 不提供任意配音和下载。

### 8.3 M2：成年访问者与公开数字分身

范围：本人主动发布内容，成年访问者在授权范围内进行文字或语音问答。

上线 Gate：

- 公开域与私人域物理和代码隔离。
- 成年状态验证。
- 依赖预警、时长提醒、退出和危机干预完成。
- 安全评估报告、算法备案和上架材料完成。

### 8.4 M3：老人健康协同与受控纪念互动

范围：老人授权的设备数据共享；权利链清晰的成人纪念互动试点。

上线 Gate：

- 健康数据专项同意和授权撤回。
- 不做诊断和用药建议。
- 纪念互动经过逐案法务审核。
- 家庭争议冻结和应急下线机制完成。

### 8.5 M4：知识许可与数字传承

范围：权属明确的知识授权、受益人指定、调用计量和收益结算。

上线 Gate：

- 权利目录、授权合同和收益结算规则明确。
- 受益人身份和争议处理完成。
- 所有生成回答保留来源与授权范围。
- 不以数字分身代理本人作法律或交易决定。

## 9. 产品整体评估

| 评估维度 | 结论 | 说明 |
| --- | --- | --- |
| 用户价值 | 高 | 自传、家族记忆、个人复盘和专业经验传承均有长期价值 |
| 政策可行性 | 条件性可行 | 行业未被禁止，但拟人化互动、未成年人和数据处理受到强监管 |
| 首版技术可行性 | 较高 | 自传、私人记忆库和有来源问答不依赖昂贵数字人即可验证 |
| 高阶技术难度 | 高 | 长期记忆准确性、实时语音、依赖识别和多权利人治理要求高 |
| 商业可验证性 | 中高 | 可先用自传服务和私人记忆订阅验证，数字人与传承收入后置 |
| 合规成本 | 高 | 声音、生物识别、健康、未成年人和逝者权利均需要专项投入 |
| 投资人理解成本 | 中高 | “复活”和“情感陪伴”容易触发负面判断，需要重新定调 |
| 可形成的护城河 | 高 | 授权链、私人记忆数据、证据追溯、安全策略和长期信任难以复制 |

### 9.1 总体结论

**项目可以继续推进，且具备形成长期个人 AI 资产平台的可能性；但不适合以“逝者数字复活平台”作为产品和融资定性。**

适合的产品定性是：

> 以自传和个人记忆沉淀为入口，以私人记忆模型为核心，以授权互动和知识传承为长期扩展的个人数字资产平台。

投资判断可以表述为：

> 这是一个高价值、高信任、高合规门槛的长期赛道。项目的机会在于记忆资产沉淀，风险在于拟人化互动失控。只要先验证低风险核心价值，并把高风险能力设置成分阶段 Gate，整体风险可收敛。

## 10. 整体规避方案

### 10.1 总体策略

采用“一个核心、三层产品、四道隔离、五个强制 Gate”的方案。

**一个核心：**

个人私有记忆资产，而不是数字人的拟真程度。

**三层产品：**

1. 记忆资产层：采集、整理、确认、导出和传承。
2. 私人 AI 层：本人检索、复盘和决策辅助。
3. 授权互动层：声音、数字分身、访问者和商业许可。

**四道隔离：**

1. 私人域与公开域隔离。
2. 成人与未成年人隔离。
3. 记忆整理与情感陪伴隔离。
4. 情感互动与商业支付隔离。

**五个强制 Gate：**

1. 身份与年龄 Gate。
2. 权利与同意 Gate。
3. 数据与供应商 Gate。
4. 内容安全与危机干预 Gate。
5. 安全评估、备案和发布 Gate。

### 10.2 立即执行的 P0 决策

1. 从产品规划中删除未成年人虚拟亲属。
2. 将“复活、永生、替代亲人”从正式产品定性和销售承诺中移除。
3. MVP 只允许在世用户克隆本人声音。
4. 私人和敏感数据默认不训练平台公共模型。
5. 建立独立的被模拟主体、上传者、权利人和受益人数据模型。
6. 在任何人格化输出前执行年龄、授权、场景和安全策略判断。
7. 完成危机退出人格模拟和紧急联系人流程。
8. 将安全评估、算法备案和 AI 标识纳入发布硬门槛。

### 10.3 上线前 P1 建设

1. 完成同意、撤回、删除、导出和供应商删除回执闭环。
2. 建立公开知识域独立副本和独立数据库读取角色。
3. 建立生成来源、AI 推断和模型版本记录。
4. 完成提示注入、跨用户泄漏、声音滥用和依赖诱导红队测试。
5. 完成投诉、争议冻结、紧急下线和停服迁移预案。
6. 形成可供投资人和机构客户查看的合规数据室。

### 10.4 验证后再做的 P2 能力

1. 成年访问者公开语音互动。
2. 老人健康设备协同。
3. 逐案审核的成人纪念互动。
4. 专家知识授权与调用计量。
5. 受益人指定和收益结算。

## 11. 决策与验收清单

以下任一项答案为“否”，对应高风险功能不得发布：

- [ ] 产品是否明确区分静态记忆服务与持续情感互动服务？
- [ ] 未成年人是否被服务端禁止使用虚拟亲属？
- [ ] 被模拟主体是否完成身份核验和场景化授权？
- [ ] 私人、公开、声音、健康和训练授权是否相互独立？
- [ ] 私人数据是否默认不用于公共模型训练？
- [ ] 公开数字分身是否只能读取独立公开副本？
- [ ] 回答是否能区分事实、用户观点和 AI 推断？
- [ ] 用户能否便捷退出、暂停、导出、撤回和删除？
- [ ] 自伤、自杀和重大财产风险是否会触发中性安全模式？
- [ ] 数字人格是否被禁止参与付费劝导和重大现实决策？
- [ ] 声音和数字人内容是否具备显式与隐式 AI 标识？
- [ ] 第三方模型的数据留存、训练、地域和删除能力是否经过验证？
- [ ] 安全评估、算法备案、隐私政策和投诉机制是否完成？
- [ ] 停服、迁移和家庭权利争议是否有可执行预案？

## 12. 最终定调

寻梦环游的真正竞争力不应是“做出最像真人的数字人”，而应是：

1. 让一个人愿意长期留下真实而完整的记忆。
2. 让记忆有来源、有边界、可纠正并归本人控制。
3. 让私人 AI 在理解长期关系的同时，不操纵、不替代、不越权。
4. 让声音、知识和收益在明确授权下被安全调用。
5. 让个人数字资产在平台变化后仍然可导出、可迁移和可传承。

因此，整体规避方案不是削弱愿景，而是改变实现顺序：

> **先记录，后理解；先本人，后他人；先生前授权，后身后传承；先建立边界，再开放拟人化互动。**

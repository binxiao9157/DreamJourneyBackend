## 已确认的核心决策

- 会中持续保存正文和主题草稿，会后集中展示。
- 待确认记忆按事件/主题归纳，多维不必多卡片。
- 有缺口可原身份补传，服务端去重；异常结束不能永久卡住已有成果。
- 接受少量细节未整理，可靠主题先形成结果；证据正确、用户纠正和权限保护不放宽。
- 不新增“正在审核”状态；待确认页面编辑可恢复，后台补充不覆盖编辑草稿。
- 积压时先提示、平稳收束，后台继续。
- 本轮20/40分钟替代65分钟，每次长场前独立短场。

60/90秒等待、补传3次、积压阈值等仍是设计建议，不是用户逐项确认或现场校准后的既定参数。实现前核对实际合同与测试依据，变更在此留痕。

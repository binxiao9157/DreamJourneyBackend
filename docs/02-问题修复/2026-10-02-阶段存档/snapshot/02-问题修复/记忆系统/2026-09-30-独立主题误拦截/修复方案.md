# 独立主题误拦截修复方案

日期：2026-09-30；关联 DJ-LIVE-INDEPENDENT-THEME-20260930。
用户授权：记录方案并开始实施。本文用于回溯，不是替代实际验收结果。

## 1. 已证事实与范围

[最新真机证据](../../../outputs/2026-09-30-live-model-contract-device/run-01/真机短场失败与直接原因.md)：两用户轮、4条正文落盘和服务器确认完整；正常停止及结束位置完整。模型提案为none，独立复核supported，同时sameSubjectEvent=false、compatibleTime=true、correctionsResolved=false、summarySupported=true。当前校验对所有关系要求四个布尔均为true，导致唯一合法独立主题被标为themeRelationUnresolved，最终noReliableThemes。

同语义本地真实relate_themes业务红已复现。此次直接断点在关系判断，不是容量、网络或正文补传。历史长场停顿和seq5首因不因此关闭。

## 2. 行为合同

先校验schema、inputHash、proposalHash及四项严格布尔类型，不把0/1、字符串、null或缺失当布尔。结构错误仍为可定位合同错误；结构有效但语义未获支持返回不接受，不修改已有记忆。

| 提案关系 | 独立复核接受条件 | 结果 |
|---|---|---|
| none | verdict=supported，sameSubjectEvent=false，summarySupported=true；compatibleTime和correctionsResolved必须为布尔，但可true或false | 保留为独立新主题，不选择/修改旧主题 |
| uncertain | 无论其他字段都不授予关联/发布许可 | 保留不确定保护 |
| supplement / duplicate / correction | supported且四项均true | 继续既有身份/证据/版本/摘要/成员校验 |
| 任意关系，复核unsupported或uncertain | 不接受 | 不自动合并或发布 |

none不是“忽略所有false”：同事件true与独立关系矛盾，摘要不受支持false不能放行。none不得携带非空duplicateAtomIds或replaces，也不得携带有效目标ID/版本/hash。none只改变是否关联既有主题；原主题组织与证据支持审核必须先通过，不能靠关系复核创造事实。

对none而言，不同时间可以是独立证据；没有纠正映射时correctionsResolved=false是合法“不适用”。提示词必须把verdict定义为对提案关系的认可，并要求有可能是补充/纠正、指代不清时返回unsupported/uncertain，不能借none绕过冲突。

## 3. 最小改动

1. `app/domain/owner_truth/live_theme_relations.py`：新增严格类型校验，按关系区分语义分支，明确none不带关联操作。保留其他关系现有事实指纹、目标版本/hash、纠正成员和非空摘要要求。
2. `app/services/owner_truth_live_theme_provider.py`：解释none复核字段的关系语义，提供独立主题复核示例；不改变4096输出上限、48000输入字节、超时、重试预算或端点。
3. 受控测试供应商：none时返回本次现场的合理false组合；相关关系仍按语义返回true。新复制测试产物，不修改既有失败/通过证据。
4. 不改iOS保存、音频、停止、补缺、候选确认逻辑，不新增审核状态，不重构已通过业务链。

## 4. 持久化与恢复边界

Worker对completed缓存读取仍执行校验；新的结构/语义规则对缓存同样生效。有效但不支持的模型回复completed仅表示该请求已结束，不能当作发布成功。修改请求使新请求hash变化，沿用原预算及缓存身份机制，不增加预算、不复活旧失败任务。

本次现场任务保留失败，不重发、不创建替代Source，不重置历史。局部修复不自动修改旧正式记忆；接受新主题仍通过现有候选→用户确认→正式记忆链。

## 5. 验收

- N01：原业务红原样运行，修后同断言为绿；不是只检测新增方法或提示词文字。
- N02：none兼容时间/纠正两个布尔4种组合可接受；同事件true、摘要false、uncertain/unsupported被阻止。
- N03：缺失/null/数值/字符串布尔、错schema/hash/target、none携带关联操作等被拒绝。
- N04：duplicate/supplement/correction任意语义否定仍阻止；原去重、补充、正式纠正、已拒绝候选不复活、并发旧版本确认防护仍通过。

## 4. 真实模型语义审阅

原始请求/响应：s1-provider-requests.json / s1-provider-results.jsonl（v1）、带v2、v3、v3repeat后缀的对应文件。保存请求hash、模型实际响应名、时间及用量，不保存凭据。

- v1：仅“大学喝过”仍说“又开始”；无历史时把时间与口味混为双重追问，判失败。
- v2：修好上述点，但把“嗯”当成确认多项猜测；用户转照片仍追问咖啡，判失败。
- v3：显式区分简短应答、退出、切题的本轮边界，并置于生成规则末尾；原11项及失败场景追加6次通过。没有改期望，也没有在模型失败后把结果替换成假输出。

| 样本 | 最终语义结论 |
|---|---|
| M01 无旧历史 | 单一时间/契机追问，无“从没喝过” |
| M02 明确喝过及停喝 | 正确连接新旧变化，无新增时间 |
| M03 仅大学喝过 | 未虚构中断；三个最终样本均不擅自“又开始” |
| M04 纠正为室友 | 按当前纠正回应，不声称正式记忆已修改 |
| M05 嗯 / 不想聊 | 不确认助手推断；退出后不追问咖啡 |
| M06 换照片 | 跟随新话题，三个最终样本未续问咖啡 |
| M07 最近两年/偶尔/计划 | 保留模糊时间、频率与计划；未重复询问已说明原因 |
| M08 检索不可用 | 可回应当前自述，不宣称无经历 |
| M09 已确认时间/原因 | 回答采用最近两年、工作忙；实际API请求事实绑定另由路由测试及PG证明 |
| M16 权限/家人 | 本地权限、旧版本与家人原提示边界通过；未用跨主体数据做外发测试 |
| M18 公共问题 | 天空知识正常；公共查询在私人索引不可用时仍执行，不夹带私人内容到搜索 |

以上是有限样本语义验收，不保证模型以后零错误；保留原失败做固定回归。纯Provider请求未走手机和部署后的完整API，不能冒充真机已使用。

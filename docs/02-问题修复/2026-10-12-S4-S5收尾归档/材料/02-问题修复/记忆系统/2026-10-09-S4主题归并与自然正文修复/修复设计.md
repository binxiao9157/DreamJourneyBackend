## 3. 实现契约

### A. 同主题的明确文字锚点

保持现有主题键兼容。对未命中预置主题、缺少可靠 object 的事实，从受限明确句式提取原文锚点（如“练习 X”“把 X 放在……”），同主体、同字面锚点才归组，与可靠 object 使用一致的键。锚点不得来自共同地点、收纳容器或泛称。多主题、代词、含多个对象、主体不明时保持独立，不猜测。

采用可解释句式而非增加“折纸”特例。每个句子保留原 memory/version/hash 引用；同主题新增事实沿用主题 ID，无关主题不变。负例覆盖不同爱好、不同人、同容器不同物、多个对象和代词。

### B. 自然整合与事实校验分离

增强模型写作指令：确有重复结构时合并表达；两个明示年份表示两次记录，不得推断中间一直保持。可将“2017年，我喜欢喝咖啡。2024年，我喜欢喝咖啡。”整合为“2017年和2024年，我都喜欢喝咖啡。”，不能写“从2017年一直到2024年”。

保留全部现有事实审核、引用完整性、数字/频率/计划/否定/相对时间保护。多事实输出如果只是原句复制、调序或改标点，不能标为 polished，应以独立质量原因保留 faithful 回退，不追加无限模型重试；单事实无需强行扩写。机械检查仅识别明确的原样拼接，不声称自动衡量全部文采。用真实 DeepSeek 样例验收阅读效果，并保存原请求/响应及调用次数。

更新算法/提示词版本，使旧“伪润色”产物不会以同 revision 继续复用；无历史批量重处理。

### C. 明示年份的等价表示

仅当 statement 恰好出现一个明确 YYYY年、validTime.expression 一致且 precision 为 year/unknown 时，可接受 start 为空或完全相同的 YYYY；不接受月份、日期、不同年份、end 或区间。比较时标准化副本，绝不改写用户已确认原文。

只有原文字面能证明、对象完全相同的明确喜好句式，才兼容中英文谓词及重复 strength 字段；冗余 summary/event 与原 statement 完全相同才可移除比较。保留主体、来源身份、否定、强度、范围、场景、计划、附加业务字段。多旧目标不任意选取；不同年份不可被同源去重吃掉。同年追加证据、异年保留时期关系，双向结果一致。

## 6. run-02：真实表示差异与验收失真修复

### 6.1 深层原因及本轮边界

- 折纸语句的 object 表示可能是被放置物，也可能是放置位置。现有代码只在 object 为空时使用原句锚点；位置值与明确宾语冲突时误回退独立事实。上一轮测试将现场事实转换为仅含 summary 的 helper，遗失 object，无法覆盖此分支。
- 咖啡关系同时遇到 object=“喝咖啡”/“咖啡”及 start=end=“2023”。前者是动宾短语/宾语的表示区别，后者在单一明确年份原句中是同一时间粒度，而非跨度区间。现有规则按字段形式拒绝，导致 noComparableCurrentFact。只处理其中一项不足以修复，已由现场最小对照证明。
- 这是内部规范化边界和验收样本保真不足，不是已证明的供应商故障、容量或超时。不能要求模型始终返回理想形状。对象角色冲突也不能一概忽略，要由原句证明等价。
- 生产改动限定正文主题识别、事实比较副本；不改提取模型契约、Live/文字/档案保存及确认事务，不改音频、认证、前端、数据库 schema。旧正式事实永不重写。三入口共享比较器的影响通过真实确认链回归。

### 6.2 实现规则

1. 对完整、明确的第一人称“我把 X 放在/进/入 Y”解析 X 与 Y。object 为空或等于 X 时按 X 归组；若 object 等于原句 Y（可含原句已明示的方位后缀），明确它是位置角色，仍按 X 归组。不得因 object 含任意地点词就忽略，不接受语义猜测；非原句值、协调多个 X、代词、另一主体、额外对象标识冲突继续保守分开。同一容器不同物品不合并。只改变投影主题键，完整原文及引用保持。
2. 对单一明确 YYYY年，expression 与原句一致，precision=year/unknown：除原有空 end 外，仅接受 start=end=同一完整 YYYY。比较副本将重复 start/end 归为相同年表示。结束值单独存在、跨年、月份/日精度、不同 expression、原句真实范围/截止含义均不视为等价。
3. 对完整字面“YYYY年，我喜欢喝 X”，在正向喜好、无最高级、无增强强度的既有边界下，允许 object.label 为 X 或“喝X”，predicate 为已支持等价词；统一比较副本的谓词、宾语与重复强度。其他对象字段、主体、场景、否定、频率和附加业务内容保留比较，未知句式不做模糊匹配。不得只替换固定“咖啡”特例；以不同饮品作变体。
4. 同年匹配允许追加证据；异年必须保留两个时期，反向顺序一致，多旧目标不任意选择。句末标点和空白处理在已有规范化语义下验证。正文算法版本更新，防止复用旧分段/旧修订；不触发历史全量重建。

### 6.3 必须通过的验收顺序

1. 冻结当前 dirty 目录，在隔离副本保存完整真机 candidate payload。正文测试使用实际 content/schema/kind 进入真实 person model，不剥离 object/qualifiers/semantic。先记录同断言修前红，再修改。
2. 变体矩阵：空对象/物品对象/原句位置对象；不同物品同容器、代词、其他人、不同实体ID、不相关位置；年份空/起点/相同起止、跨年/月份/真实区间；中英谓词、动宾对象、同年重复、正反顺序、否定/强度/场景/附加字段保护。
3. 隔离 PostgreSQL 使用当前 migrations、生产确认服务、真实事务及新连接冷读；完整现场 payload 验证 add→temporalChange→addEvidence，旧时期正式内容/身份不变；两折纸事实经真实确认后同主题两份精确证据，无关照片块不变。
4. 默认 API 正常 lifespan、默认候选 Worker、实际 HTTP 模型传输层和隔离 PostgreSQL 完成短→逻辑长保存保护。受控响应只用于确定性故障/边界回归，不冒充真实模型。
5. 真实模型通过现有授权配置执行新的合成提取与正文整合，保存实际响应完整结构，在最终比较器/投影中验证，不能先手工改字段再验收。至少覆盖档案组织与 Live/文字所用组织路径的真实返回；明确各入口是否实际覆盖。结果不符合预期则保留反例并修正同一设计，不靠重抽直到绿。正文写作/审核预算不变。
6. 受影响回归通过后才按 baseline 指纹应用回工作目录；检查最终源文件一致。iOS产品文件未改则复用同版已有开麦/音频证据并说明本轮未新跑真机，不把后端本地结果冒充麦克风/声学通过。部署及新真机另记版本与状态。

### 6.5 run-02 真实模型新增反例：事实通过不等于成文通过

首次新的真实组织与写作验证中，折纸两条已经正确进入同一主题，但 writer 返回“我把折纸放在白色收纳盒里，每周日下午在家练习折纸。”，只是原句改标点。独立审核判事实 supported，机械质量检查仍正确返回 compositionNotIntegrated，正式事实未受影响。该次失败必须保留，不能只保留后来成功样本。

在第6.1节的边界上补充：允许调整原有正文 writer 的指令与提示词版本，增加“练习＋收纳”的具体正反例，明确优先围绕活动叙述、用明确指代减少重复，不得添加“练习后收纳”等未经证实的时序。保留原有两次 write/audit 预算，不增加生产重试、不放宽质量或事实检查。将本次真实失败输入/响应做固定负例，并针对修改后提示词重新采样一次两主题完整 PG 链；再用不同物品、时间、颜色的合成样本核对泛化，若仍失败如实保留。

时间等价实现进一步收窄：对于新增的 start=end=YYYY 分支，必须由完整“YYYY年，我喜欢喝 X”句式证明单年喜好，未知句式维持保守；旧空 end 支持不扩展。直接测试截至、从某年开始及跨度句式不能进入此新增分支。

### 6.6 run-02 第二个真实反例：自然衔接不得扩大时间作用域

v5 writer 已按示例生成“我每周日下午在家练习折纸，折纸则放在白色收纳盒里。”，audit 拒绝：一是“则”可能引入对比，二是前半句时间可能被理解为限定后半句收纳。原响应完整保留。此次拒绝不能靠改 supported 或放宽事实门槛消除。

修正第6.5节的正例：同段允许多个自然句，不强迫全部事实压成一个句子。只有共用时间/否定/计划等限定已由原文证明时，才合并句式；限定不同则断句并分别引用。练习/收纳样例可写“每周日下午，我在家练习折纸。我用白色收纳盒放这些折纸。”，第二句不继承第一句时间，不新增收纳发生在练习前后。审核明确允许不改变含义的语法改写和明确指代，仍必须拒绝新增关系或限定转移。提示词升级 v6，预算不变；两次真实失败作为负例回归，原事实仍可忠实读取。

### 6.7 保留计划与否定时的成文质量

v6 的折纸/咖啡 PG 链及陶笛、书法变体通过，但“大学时偶尔喝咖啡＋打算周末喝、还没有开始”样例被模型逐句照抄，事实审核通过、质量门禁失败。新增写作自检：限定必须保留不等于语法必须照抄；不同限定仍分句，但应自然改写各句。增加保持“偶尔/打算/还没有开始”的示例，不新增经历、动机、转折或再度开始。提示词升级 v7，并在修改后只执行一次固定样例集（含相对时间及否定）；失败不得以额外重抽掩盖。所有真实响应按版本留档。若仍有质量失败，则忠实回退及正式记忆链需验证成功，报告明确该质量缺口，不宣称全部样例润色通过。

# 声音驱动光球：实施与验证

日期：2026-10-03。对应[设计方案](2026-10-03-声音驱动光球设计方案.md)。本报告限定于回响光球，不是整套 Live/记忆功能的新一轮真机验收。

## 实现

- EchoPresentationViews.swift：以 UIKit + MTKView 替换固定缩放动画；蓝白云纹由真实输入/输出音量驱动，安静时仅缓慢流动。没有再用 speaking 状态生成虚拟音量。
- EchoOrbShader.metal：复用 ElevenLabs 的顶点渲染与基础噪声方法；实际查看第一版渲染发现极坐标中心辐射纹过强，改用平面坐标扰动的柔和云层。颜色为可配置的两组蓝白参数，无新的 Swift Package 或音频 SDK 依赖。
- DialogEngineManager.swift：仅在原生 Provider Live 模式开启既有 SDK recorder PCM 观察。input 来自 recorder，output 来自 player，保持原播放器 PCM 完成校验路径。每声道最多 30Hz、最多一个待处理 UI 样本；固定上限的 RMS 采样；新录音观察不进入正文/诊断落盘队列。
- EchoViewController.swift：接收轻量音量样本，投给光球，不修改转写、主题、候选审核、正式记忆或停止完成条件。
- 生命周期：账户/引擎/operation 的原有校验仍执行；旧场样本不得进入新场。视觉层拒绝超过 180ms 的陈旧样本；退出、后台、关闭时归零。包络快速跟随、缓慢回落。30fps 上限、低电量 15fps、drawable 最长边 600px；减少动态效果时暂停运动。Metal 不可用或管线创建失败时为静态渐变。
- Apache-2.0 LICENSE 与 NOTICE 加入 App 资源；固定上游版本、原始源码保存在本轮证据目录。

## 验证口径

真实 Metal 渲染到纹理，并检查透明边缘、中心 alpha、uniform 的 96 字节布局；在同一时间分别输入静音/录音/回复音量，像素结果必须不同。另有实际 MTKView 接收新鲜样本、关闭归零和禁用 Metal 降级断言。基础 PCM 测试覆盖静音、噪声底、响度单调性、异常字节和过期回落。

受控 SDK 配置运行生产 Manager 编排，包括原 delegate proxy、会话身份校验和 Echo 接收入口，确认录音/播放样本抵达，关闭后旧回调被拒绝。它模拟的是 SDK 边界，不能冒充真实火山二进制音频回调或真机同步效果。

首次构建因本机未安装 Metal 编译组件失败，已通过 Apple `xcodebuild -downloadComponent MetalToolchain` 补齐。首轮普通回归出现 1 个测试装配失败：在单元测试中调用 XCUIScreen 截图，不具备 UI 测试权限。已移除该截图调用，保留真实 GPU 渲染与生命周期断言，失败产物未删除。普通 `CALayer.render` 的页面图不包含 Metal 图层，不作为光球缺失或成功的现场证据。

最终计数见下方最终结果。本轮没有做真实 Provider、手机安装或真机测试，没有部署、提交、推送，也没有操作生产/历史任务。

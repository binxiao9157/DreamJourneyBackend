# 转写差异不中断真机测试

用户授权：修改测试工具。范围仅 tools/live_device_lab，及由 stage 生成的隔离自动化 App。正常 iOS、后端、模型调用、保存与候选发布规则不变。本轮不部署、不操作手机、不调用真实模型、不推送。

## 原因与目标

第28轮“不赶进度”转为“不敢进度”，现有工具在真实播放结束后抛 asrFactMismatch；即使不抛异常，完成条件仍要求预设关键词全部匹配，会继续等到超时。该内容断言错误地承担了对话流程控制，因此约565秒主动关麦，破坏十分钟自然告别验收。

关键词差异不是音频或持久化故障。拆开流程验收和内容验收，不通过扩大同音字归一化来冒充语义正确。

## 改动

1. 一轮完成仍须有本轮非空 ASR final、与其一致的用户显示文本、助手文本、非静音音频、真实播放完成、恢复聆听或进入产品告别。预设关键词不再决定是否继续。
2. 逐轮记录关键词匹配结果、缺失词、实际转写及音频/文本指纹。修订后的最终持久化正文作为收尾内容核对依据，保留逐轮观测，不能用旧转写覆盖最终正文。
3. 对话结束后继续核对完整磁盘正文、服务器 Source 身份和正文、候选绑定和实际列表。若最终正文仍存在关键词差异，记录 CONTENT_REVIEW_REQUIRED，停止在自动正式确认之前；不发送确认命令，不生成正式读取凭证或短场通过凭证。
4. 主机识别 CONTENT_REVIEW_REQUIRED 为有结果的待核对终态，退出码2；不等待超时、不称整场失败/通过、不自动开始下一场。差异人工判断后后续确认须绑定原场候选，不能重放 Live 或泛化为以后全部差异放行；本轮不新增自动审批接口。
5. 真正流程故障保留 FAIL 和首错，仍执行原有有限收尾观察；如恢复后发现内容差异，原 FAIL 不改写，仅确认阶段待核对。

## 影响与不变量

ASR 漏词、同音和否定词变化都记录并继续，均不自动认定可接受。没有 ASR、没有真实播放、账户变化、身份错绑、持久化缺失、未知确认结果仍受原保护。十分钟600秒门槛和自然告别、逐场清理、独立短场门禁及指纹约束不变。历史报告和旧工具副本不改写。

## 验收

- 同音差异与否定语义变化：完成条件允许继续，最终内容核对仍待人工；下一轮可完成。
- 空转写、未显示当前转写、无助手文本、无非静音播放、未回到聆听均不能误过。
- 迟到转写修订：最终持久化一致时解除内容差异，身份不一致仍拒绝。
- 主机立即返回待核对结果，不能签发短场门禁或进入冷读。
- 运行现有 Python 回归、实际 Swift 策略/账本测试、隔离工具 App 编译；集成测试相应更新，未执行的外部或服务依赖测试明确标注。
